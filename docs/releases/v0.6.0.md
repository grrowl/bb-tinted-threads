# Tinted Threads 0.6.0

Tinted Threads is now built on bb's own sidebar.

Earlier versions were a separate thread list that we wrote from scratch. Since
then, bb's stock sidebar has gained drag and drop, an archive button on each
row, custom sections, and more. Keeping up meant writing each of those
features again, and the stock sidebar still did not show which threads needed
you.

Version 0.6.0 is a fork of bb's built-in thread list. It has every feature of
the stock sidebar, and Tinted Threads adds its status tints and extra detail
on top. When bb improves its sidebar, we rebase the fork, so you get the new
features too.

## What you get from bb's sidebar

- Drag a thread to reorder it, nest it under another thread, open it in a
  split, or drop it into the composer.
- Archive a thread with the button on its row.
- Rename a thread inline, and use the full thread actions menu.
- Create your own sections with **New section** in the list menu.
- Organize by project, by machine, or into custom sections, and optionally
  group threads by environment.
- bb syncs your sections, order, and collapsed rows across devices.

## What Tinted Threads adds

- **Status tints.** A row turns red when the thread needs you and green while
  work is running. This is the feature Tinted Threads started with, and it
  works the same way as before.
- **Sub-thread counts in the expand button.** A parent row shows `[6 ›]`, and
  the button is green or red when a sub-thread is working or needs you. Hover
  the number to see the count for each status.
- **Subtitles.** The line under each title can show the model, the project,
  the workspace, and the uncommitted diff. Turn each one on or off under
  **Organize → Rows**. The project subtitle is new in this release.
- **Pull request status at the right edge of the row.** Titles have more room
  because the pull request state no longer sits in the subtitle.
- **Density.** A new **Density** menu has Default, Comfortable, and Compact
  row spacing. Compact matches bb's stock sidebar.
- **Hide empty projects.** When you organize by project, **Organize →
  Sections → Hide empty** hides projects that have no threads to show.
- **More room for titles.** Rows keep less empty space on the right, and the
  expand button stays in the same place when you hover a row.

## Faster

Version 0.5 could slow down all of bb while agents were working. Every time a
thread changed, it asked the server again about every visible thread, and
those requests delayed bb's own requests.

Version 0.6.0 reads each thread's status from the data bb already sends to the
sidebar, so the tints need no extra requests. The plugin fetches subtitle and
pull request details only for rows on screen. It sends them in batches, one
request at a time, and caches the results.

## Before you upgrade

- Tinted Threads 0.6.0 needs bb 0.44.0 or later.
- Your settings from 0.5 are not carried over. The list starts from the layout
  of bb's stock sidebar, and the subtitle settings start at the old defaults.
  The model, pull request, and workspace subtitles are on, and the diff
  subtitle is off.
- Settings now live in the list's own menu, not under Extensions → Plugins.
- Some 0.5 features are gone because bb's sidebar has its own version:
  - Sort by attention is gone. Sort by **Updated at** is the closest option.
  - Manual sort is gone. Drag threads to reorder them, or use custom
    sections.
  - Group by environment is now **Organize → Groups → By environment**.
  - A flat list is now the **Custom** organize mode.
- The subagent count on running rows is gone. A running row with background
  agents is tinted green instead.

## Install or update

```sh
bb plugin install git:https://github.com/grrowl/bb-tinted-threads.git@v0.6.0
```

If you already use Tinted Threads, run `bb plugin update tinted-threads`. If
bb finds no update because your install is pinned to an older tag, run
`bb plugin remove tinted-threads` and then the install command above. Your
choice in Settings → Appearance → Sidebar stays the same.
