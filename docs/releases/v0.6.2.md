# Tinted Threads 0.6.2

Restores the status breakdown in the sub-thread expand button from before 0.6.

- Counts appear in stalled/running/idle order, e.g., `1/2/1`, with stalled
  counts in red, running counts in green, and idle counts in grey.
- Zero counts are omitted, so two running and one idle sub-thread show `2/1`.
- Hover the counts to see the total and status labels.
